## Как дополнять каталог

Когда появляется новая работа, достаточно добавить ссылку на её репозиторий или папку в таблицу нужного семестра. Если дисциплина уже есть в списке без подборки, её строку можно перенести в основной каталог.

Внутри [папки «Матан»](./%D0%9C%D0%B0%D1%82%D0%B0%D0%BD) и других общих архивов сохранена исходная организация файлов; отдельные репозитории остаются самостоятельными проектами.
