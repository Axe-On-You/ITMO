\# Collatz Fractal Renderer



Лабораторная работа №4 по дисциплине \*\*«Языки программирования»\*\*.



Проект реализует генерацию и визуализацию \*\*Collatz Fractal\*\* с плавным приближением:

\- вычисления выполняются на \*\*C#\*\*

\- отрисовка кадров выполняется на \*\*C\*\*

\- результат собирается в видео



---



\## Общая идея



1\. \*\*C# проект\*\* вычисляет значения фрактала Коллатца для каждого пикселя кадра  

2\. Каждый кадр сохраняется в бинарный файл (`.bin`)  

3\. \*\*C проект\*\* читает бинарные файлы и конвертирует их в изображения PNG  

4\. Из PNG собирается видео с помощью `ffmpeg`



---



\## Как запустить



\### 1. Генерация кадров (C#)



1\. В Visual Studio выбрать проект \*\*CollatzCalculator\*\*

2\. `Set as Startup Project`

3\. Запустить (\*\*F5\*\*)

4\. В папке `frames/` появятся файлы `frame\_XXXXX.bin`



---



\### 2. Рендер изображений (C)



1\. В Visual Studio выбрать проект \*\*CollatzRenderer\*\*

2\. `Set as Startup Project`

3\. Запустить (\*\*F5\*\*)

4\. В папке `frames/` появятся файлы `frame\_XXXXX.png`



---



\### 3. Сборка видео



В папке `frames/` выполнить:



```bash

ffmpeg -framerate 30 -i frame\_%05d.png -c:v libx264 -crf 18 -pix\_fmt yuv420p -vf "scale=1280:720" fractal\_collatz\_hd.mp4```
